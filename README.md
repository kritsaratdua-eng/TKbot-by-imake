# TinkerBott

ส่วนเสริม (Extension) สำหรับรถของเล่น **ACEBOTT TinkerBott V2.0** เพื่อใช้งานร่วมกับบอร์ด micro:bit ผ่านโปรแกรม MakeCode

---

## 🛠️ การติดตั้งส่วนเสริม (Installation Guide)

ในการเริ่มต้นใช้งาน คุณจำเป็นต้องเพิ่มส่วนเสริมนี้เข้าไปในโปรเจกต์ MakeCode ของคุณก่อน:

1. เปิดเบราว์เซอร์แล้วไปที่ [MakeCode for micro:bit](https://makecode.microbit.org/)
2. คลิก **New Project** เพื่อสร้างโปรเจกต์ใหม่
3. คลิกเมนูรูปฟันเฟือง ⚙️ ด้านขวาบน หรือเลื่อนแถบเมนูเครื่องมือ (Toolbox) ลงมาด้านล่างสุด แล้วเลือก **Extensions** (ส่วนขยาย)
4. คัดลอก URL ของหน้า GitHub นี้ (หรือพิมพ์ค้นหา `TinkerBott`) แล้ววางลงในช่องค้นหา 
5. กดปุ่ม `Enter` (หรือไอคอนค้นหา) จากนั้นคลิกที่กล่อง **TinkerBott** เพื่อทำการติดตั้ง
6. เมื่อติดตั้งสำเร็จ คุณจะพบเมนู **TinkerBott** ปรากฏขึ้นในแถบเครื่องมือ พร้อมใช้งานบล็อกคำสั่งต่างๆ ทันที!

## 🚀 แนะนำการใช้งานเบื้องต้น (Basic Usage)

ส่วนเสริมนี้มีบล็อกคำสั่งภาษาไทยที่ถูกจัดหมวดหมู่ให้ใช้งานได้ง่าย ดังนี้:

### 1. การควบคุมรถไมโครบิต (Microbit Car)
- **ตั้งค่าทิศทางรถ**: สั่งให้รถ เดินหน้า ถอยหลัง เลี้ยวซ้าย หรือเลี้ยวขวา พร้อมกำหนดความเร็ว
- **ควบคุมความเร็วแยกอิสระ**: กำหนดความเร็วล้อซ้ายและล้อขวาแยกกัน (-100 ถึง 100)
- **เคลื่อนที่ตามเวลา**: สั่งให้เคลื่อนที่ตามทิศทางที่กำหนดในช่วงเวลาที่ต้องการ (หน่วยเป็นมิลลิวินาที)
- **หยุดรถ**: สั่งให้มอเตอร์ทุกตัวหยุดทำงานทันที

### 2. การควบคุมไฟ LED และสี
- **ตั้งค่าไฟ LED**: เปลี่ยนสีไฟหน้า (ซ้าย, ขวา หรือทั้งหมด) โดยเลือกจากจานสี
- **ผสมสีเอง (RGB)**: กำหนดค่าสี R (แดง), G (เขียว), B (น้ำเงิน) แยกอิสระ (0 - 255)

### 3. การใช้งานเซ็นเซอร์ (Sensors)
- **อัลตราโซนิก (Ultrasonic)**: วัดระยะห่างจากสิ่งกีดขวาง (ซม. หรือ นิ้ว)
- **เซ็นเซอร์เดินตามเส้น (Line Tracking)**: อ่านค่าพื้นสีดำ-ขาวจากเซ็นเซอร์ซ้าย/ขวา

### 4. ตัวรับสัญญาณ IR (IR Receiver)
- **ตั้งค่าตัวรับสัญญาณ**: เริ่มต้นใช้งาน IR ที่ขาที่ต้องการ
- **เหตุการณ์การกดปุ่ม**: ตรวจจับว่าผู้ใช้กดหรือปล่อยปุ่มใดบนรีโมท (▲, ▼, ◀, ▶, OK, 0-9, *, #)

## 🏆 ฟีเจอร์ระดับสูง (Advanced Features)

### 5. การเดินตามเส้นแบบ PID (PID Line Tracking)
ช่วยให้รถเดินตามเส้นได้อย่างสมูทและแม่นยำกว่าการเช็คค่าแบบธรรมดา:
- **ตั้งค่า PID**: ปรับจูนค่า Kp, Ki, Kd เพื่อให้รถตอบสนองต่อเส้นได้ดีที่สุด
- **ความเร็วฐาน**: กำหนดความเร็วหลักที่รถจะใช้วิ่ง
- **เริ่ม/หยุด PID**: เปิดใช้งานระบบประมวลผล PID ในพื้นหลังอัตโนมัติ

### 6. การใช้งานร่วมกับกล้อง AI (HuskyLens AI Vision)
เชื่อมต่อความสามารถด้านปัญญาประดิษฐ์ผ่านพอร์ต I2C:
- **เชื่อมต่อกล้อง AI**: ตรวจสอบการเชื่อมต่อกับ HuskyLens
- **โหมดการทำงาน**: เลือกโหมด เช่น จดจำใบหน้า, ติดตามวัตถุ, หรือจดจำแท็ก
- **ขอข้อมูล**: ดึงพิกัด (X, Y), ขนาด (Width, Height) และ ID ของวัตถุที่ตรวจพบ
- **วิ่งตามวัตถุ**: สั่งให้รถวิ่งตามวัตถุที่กล้องตรวจพบโดยอัตโนมัติ

### 7. รีโมทคอนโทรลเลอร์ (Remote Controller)
รองรับการเชื่อมต่อกับ micro:bit Joystick:
- **อ่านค่าจอยสติ๊ก**: ดึงค่าแกน X, Y และสถานะปุ่มกด
- **ปุ่มทิศทาง**: อ่านสถานะปุ่ม บน, ล่าง, ซ้าย, ขวา
- **มอเตอร์สั่น**: ควบคุมการสั่นเพื่อแจ้งเตือนผู้ใช้งาน
